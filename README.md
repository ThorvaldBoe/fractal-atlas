# Fractal Atlas

An interactive browser based fractal explorer and generator.

## Features

- Explore the Mandelbrot set, Julia set, and Burning Ship fractal
- Build a polynomial variant with adjustable power and conjugate weight
- Pan, zoom, adjust iteration detail, and choose color palettes

## Run locally

Open `index.html` in a modern browser. The deployable site build is in `dist/index.html`.

Live site: https://fractal-explorer.tmanviking.chatgpt.site
